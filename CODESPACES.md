# ASTRAA — GitHub Codespaces

This workspace is for inspecting, fixing, and testing the project code from a phone/browser.

## Important

GitHub Codespaces is a CPU development environment. It is **not** the GPU runtime for LTX-Video generation.

Use Codespaces for:
- fixing Python/notebook code
- validating JSON and Python syntax
- preparing prompts and scripts
- committing changes directly to GitHub

Use a GPU runtime separately for actually generating LTX videos.

## Open

GitHub repository → **Code** → **Codespaces** → **Create codespace on main**.

After the codespace opens, the repository is already mounted in the VS Code workspace.
